# Security Policy

Report vulnerabilities to **security@xailens.com**. Do not open a public GitHub issue.

Acknowledgement within 48 hours, initial assessment within 7 days, status updates at least every 14 days, public disclosure after a fix is deployed.

The full security model (authorities, multisig setup, program invariants, audit scope, operational rules) is in [docs/SECURITY.md](docs/SECURITY.md).
